# Zomato Restaurant Data Analysis 🍽️

## Project Overview
This project explores the Zomato Bangalore restaurant dataset to understand the factors associated with restaurant ratings.

The main research question is:

**What drives a restaurant's rating on Zomato?**

## Objectives
- Understand the distribution of restaurant ratings.
- Identify locations with the highest number of restaurants.
- Explore the most common cuisines.
- Compare ratings based on online ordering availability.
- Investigate the relationship between restaurant cost and ratings.
- Analyse correlations between ratings and selected restaurant features.

## Tools and Technologies
- Python
- Pandas – Data cleaning and manipulation
- NumPy – Numerical operations
- Matplotlib – Data visualisation
- Seaborn – Statistical visualisation

## Project Workflow
1. Data loading and initial inspection.
2. Handling missing values and duplicate records.
3. Cleaning rating and cost columns.
4. Exploratory data analysis using visualisations.
5. Spearman correlation analysis.

## Dataset
Source: [Zomato Bangalore Restaurants – Kaggle](https://www.kaggle.com/datasets/himanshupoddar/zomato-bangalore-restaurants)

The dataset contains information about restaurants in Bengaluru, including ratings, cuisines, locations, cost, online ordering and table booking availability.
